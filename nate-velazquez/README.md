# Nate Velázquez — Oferta + Sistema de Ventas

Todo lo que Nate necesita para vender su coaching: qué vende, a quién, a qué precio, y qué decir en cada paso desde el primer mensaje hasta el onboarding.

> **Supuestos a validar con Nate** (marcados con `[AJUSTAR]` en los documentos):
> - Coaching 1:1 online (entrenamiento + nutrición), cliente ideal: hombres y mujeres de 25–45 años con trabajo y poco tiempo.
> - Precio de referencia en USD. Si vende en otra moneda o mercado, ajustar los números del stack de valor manteniendo las proporciones.
> - Canal principal: Instagram (contenido → DM → llamada).
> Si alguno no aplica, cambian los nombres y los números, pero el proceso es el mismo.

## El proceso en una línea

```
Contenido  →  DM / historia  →  Calificación por chat  →  Llamada de venta  →  Pago  →  Onboarding  →  Resultados  →  Testimonio  →  Más contenido
```

## Cómo usar esto

1. Leer la oferta (01) hasta poder explicarla en 30 segundos sin mirar.
2. Practicar el guion de llamada (04) en voz alta al menos 5 veces con alguien que haga de cliente difícil.
3. Usar el guion como mapa, no como lectura: las preguntas son fijas, las palabras se adaptan.
4. Registrar cada conversación en la planilla de métricas (02) y revisar los números cada domingo.
